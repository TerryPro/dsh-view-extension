# dsh-diff-view

给 DeepSeek Harness 会话区加一个**详细 diff 视图**：左边是改动文件列表，右边是选中文件的对比详情。它作为「对话 / 轨迹」旁边的第三个视图页签挂在**轨迹视图的右边**，两个数据来源可以在面板内切换：

| 范围 | 回答什么问题 | 数据来源 |
|---|---|---|
| **工作区** | 相对 `HEAD` 的**全部未提交改动**（已暂存 + 未暂存 + 未跟踪） | `git status --porcelain=v2` / `git diff HEAD` / 未跟踪文件按新增逐行展示 |
| **本次会话** | 这个会话里 agent **逐轮改过**的文件 | ① Host 的 `workspaceChanges` 记录（按轮次汇总，同一文件多轮改动显示最新一轮并列出所有轮次）；② 会话日志里的 `write`/`edit` 工具调用（在 ① 没有记录时兜底列文件，此时没有前后对比可看） |

```
┌─ 工作区 │ 本次会话 ──────────────── 12 个文件  +238 −41   [筛选…]  ● ↻ ┐
├──────────────────────────┬───────────────────────────────────────────────┤
│ M client/client.js  +21 −1│ client/client.js        修改 +21 −1  ⇄ ¶ ⧉   │
│ M lib/git.js        +64 −3│ ┌───────────────────────────────────────────┐ │
│ R lib/old.js →  new.js    │ │ @@ -1601,10 +1601,30 @@                  │ │
│ U tools/smoke.mjs    +30   │ │ 1601 1601   return;                       │ │
│ …                         │ │ 1602      -  old line                     │ │
│                           │ │ 1602 1603 +  new line                     │ │
└──────────────────────────┴───────────────────────────────────────────────┘
```

## 它为什么长这样

**一个视图页签，不是新开一栏。** 轨迹视图本来就占满会话区中栏，所以「轨迹旁边的 diff」就是轨迹的兄弟页签，而不是新的一栏。外壳已经有这个座位：`conversation.view`（`DefaultConversationViews` 一次只渲染一个条目）。插件往这个列表里加一项，就白拿了页签条、会话作用域和生命周期；卸载即完全消失，没有任何 DOM 手术。

**Host 出数据，浏览器出画。** 浏览器跑不了 `git`，也读不到会话的逐轮改动记录（那在 Host 内存里），所以两者都由插件的 Host 半边算好，通过 `/api/dsh-diff/*` 以 JSON 返回：
| 路由 | 方法 | 作用 |
|---|---|---|
| `/api/dsh-diff/files` | GET | 某个范围（`git` / `session`）的改动文件、状态与行数 |
| `/api/dsh-diff/file` | GET | 单个文件的结构化 hunks |

请求**只带会话 id，不带路径**：工作目录由 Host 从会话自己的 header 解析（优先 `sessionQuery`，回退到活跃 agent 表）。所以构造请求最多只能指定一个用户本来就开着的会话，无法让插件去读任意目录。

**行数用一条 `git diff --numstat` 拿。** 已暂存和未暂存的改动**合并**报告（`git diff HEAD`），所以同一文件的两处改动不会各算一次；未跟踪文件没有 index 条目，由 Host 自己按行数计，二进制和超限分别降级成「二进制」和「不计数」。

**`--line-prefix` 是分隔符，不是装饰。** `git diff` 的正文行可能本身就以 `diff --git`、`--- ` 或 `@@` 开头。Host 给每一行加一个路径里不可能出现的控制字符，然后先剥标记再分类，于是「正文里的 `@@`」和「hunk 头」永远不会混淆。

**重命名不做重命名检测。** 列表把 `R old → new` 作为元信息画出来，但单个文件的对比**故意不加 `-M`**：给了单个 pathspec 之后，`-M` 可能判定「这是个全新文件、和原来没差别」，而这是对比最不该给出的答案。

**复制路径按钮**用 `navigator.clipboard`（不可用时静默失败），**换行偏好**存在浏览器 `localStorage`，和外壳其它布局状态放在一起。

## 它刻意不做的事

- **不做语法高亮**：外壳的高亮器是打包进去的服务，第三方 bundle 引用不到（`require` 只认平台白名单里的名字）；半亮不亮的 diff 比朴素的更难读。
- **不写入**：没有 stage / revert / 保存，路由全部只读。
- **不读任意目录**：见上面的会话寻址。
- **不缓存**：换一次会话就重新读一次——diff 是移动中的工作区的快照，陈旧的比转圈更糟。

## 布局与交互

- 顶部：范围切换、文件数与 +/− 汇总、文件名筛选、自动刷新开关（每 4 秒，页面隐藏时不刷新）、手动刷新
- 左栏：每行一个文件 —— 状态字母（`M`/`A`/`U`/`D`/`R`/`C`/`!`/`B`/`L`）、文件名、所在目录、`+n −n`；键盘可达（`aria-selected` + `listbox`）
- 右栏：文件名、状态、行数、**并排/统一**切换、**换行**切换、复制路径；正文按 hunk 分段，带 `@@` 头、双侧行号、`+`/`-`/空格标记
- 空态、加载态、错误态各有自己的文案和重试入口；「不在 git 仓库里」「这台机器没有 git」「本次会话还没有记录改动」都是**正常答案**，用一条说明横幅表达，不是报错

## 安装

```bash
# 装进 desktop profile（自带 link，无需重新构建）
dsh plugin add link:F:/deepseek_harness_workspace/dsh-diff-view
```

或者直接在设置 → 插件里安装这个目录。装好后 Host 半边立刻挂载路由；浏览器半边由 client 模块图提供（包名即模块 id），刷新页面后生效。

## 目录结构

| 文件 | 角色 |
|---|---|
| `index.js` | Host 半边：只声明 `webServer`，把路由族挂上去 |
| `lib/http.js` | 路由族共用的 HTTP 词汇：JSON 写入、错误信封、本机围栏 |
| `lib/git.js` | `git` 执行器、porcelain/numstat 解析、unified diff 解析、未跟踪文件读取 |
| `lib/session.js` | 会话工作目录解析、逐轮改动汇总的折叠与定位、日志里的文件工具兜底 |
| `lib/routes.js` | 两条路由：文件列表与单文件对比 |
| `client/client.js` | 浏览器半边：`conversation.view` 页签、数据控制器、diff 渲染 |
| `tools/test-host.mjs` | Host 测试：真实临时 git 仓库 + 真实 git 输出 + 假 Host 上下文驱动路由 |
| `tools/smoke-client.mjs` | 浏览器半边测试：VM realm 里跑真实 bundle，迷你 React 渲染并断言交互 |

## 测试

```bash
node tools/test-host.mjs      # 58 项：解析器对真实 git 输出、路由行为、会话折叠与兜底、围栏
node tools/smoke-client.mjs   # 65 项：契约、注册、渲染、交互、失败态
npm test                      # 两个都跑
```

Host 测试会现建一个临时仓库，覆盖：已提交的修改、已暂存的半步改动与未暂存改动合并计数、重命名后再编辑、未跟踪文件、二进制文件、路径逃逸拒绝、非仓库目录、未知会话、缺参数、网络对端拒绝，以及会话范围的记录折叠、兜底列表（相对/绝对路径、`read` 不算改动、坏 JSON 参数不影响列表）和「没有留存对比」的诚实答复。浏览器测试会把真实 bundle 跑在 VM realm 里，用迷你 React 渲染，覆盖：页签身份与顺序、样式表归属、列表读取、自动选中、hunk 行号与标记、单侧对比忽略并排、换行偏好持久化、筛选、范围切换与会话坐标、失败列表 / 失败对比 / 空范围 / 非仓库的状态与文案。

## 已知限制

- **会话范围的对比依赖改动记录器**：`workspaceChanges` 只为活跃会话保留记录，而且只在它确实算出改动时才留下条目（没有工具结果的轮次、当前这一轮尚未结束时都不会有）。Host 因此还会读**会话日志里的 `write`/`edit` 调用**兜底列文件；这些行会标明出处，右侧显示「Host 没有为这次改动留下前后对比」，并提示切到「工作区」看它现在的差异。
- **会话范围按文件取最新一轮**：一个文件改了多轮时，右侧显示的是**最新一轮**的前后对比，不在一个视图里合并多轮。列表会列出改动过的轮次（`changedTurns`）。
- **兜底列表不带行数**：它只知道「哪些文件被文件工具碰过」，不知道改了多少行，所以这些行的 `+n −n` 是空的。
- **未跟踪文件超过 2 MiB 只给状态不给行数**，二进制文件同理。
- **git 范围以 `HEAD` 为基线**：没有提交、没有暂存区语义之外的「和某个提交比较」选择器。
- **Host 半边改动需要重启 DSH**：浏览器半边由 client 模块图按需服务，刷新页面即可更新；但插件 Host 半边的模块不会被热替换，改了 `index.js` / `lib/*.js` 要重启（或让桌面应用重开）才生效。
