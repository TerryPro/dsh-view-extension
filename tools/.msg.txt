dsh-diff-view: the changes tab becomes a git browser

The working-tree view went empty after every per-round commit, which is the very
workflow this plugin created. History is what is actually worth reading.

- left column: the commit list, with "working tree (uncommitted)" as its first row
- right column: what the selection touched (a third) above that file's comparison
- a commit's own files come from diff-tree --root --first-parent; its file diffs
  read in the new commit scope (?scope=commit&at=<sha>)
- the checkpoint button stays (the only write), and a commit re-reads the history
- the session scope, the turn strip and the delta/state axis are gone by request,
  with their styles

Two defects the new tests caught:
- fileUrl formatted `at` as a session coordinate for every scope, so a commit read
  asked for `at=<sha>:undefined:undefined` -- a read that could only fail;
- a failed history read replaced the whole column, including the working-tree row
  that needs no repository at all.

170 host checks (15 new: log parsing, paging, the root commit, commit files and
statuses, the commit scope, a bad commit), 271 client checks.
