dsh-diff-view: a button box must fit its label

`.dshdv-btn` was an ICON button: a fixed `width:28px`. Eleven text labels were
later put on that same class (预览 / 编辑 / 高亮 / 重试 / 仍然覆盖 ...), so each
label was squeezed into a one-character column -- the editor head, meant to be
32px, became a ladder of letters and the path column was squeezed to nothing.

The fix is one rule: `width:28px` -> `min-width:28px` + `white-space:nowrap`.
An icon button still measures 28x28 (16px glyph + 6px padding each side); a text
button now grows to the word it carries. The head uses `min-height` and its
status keeps its own width, so a label can no longer dictate the row's height.

The old tests could not catch this: the harness has no layout engine, so no DOM
assertion can see text wrap. The guards therefore check the RULES -- the button
box must not fix a width, the label must not wrap, the head must not be sized by
its content -- plus one that no header label renders as its own raw dictionary
key.
