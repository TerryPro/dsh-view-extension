dsh-diff-view: browse every file type, edit the ones that are editable

Follows the reference implementation's own call (DSH-better-sidebar
builtins/viewers.tsx): the shell already ships read-only previews for images,
PDFs, office documents, spreadsheets and text with zoom and auto-refresh, so
this plugin yields those instead of re-drawing them, and keeps the two surfaces
a previewer is not.

- text (default) -> the editor, Ctrl/Cmd+S, conflict-checked save, highlight mode
- markdown -> the shell's own MarkdownText, one toggle from editing
- html -> a sandboxed iframe (sandbox="", no allow-scripts) on the raw route
- everything else -> "open in the shell previewer" plus a download, handed over
  as dsh-resource://file/session/<id>/<path> through sidebarRight.openResource;
  a refused hand-off is reported where the action was taken

New route /api/dsh-diff/raw serves bytes with a content type for the frame and
the download, under the same containment check and cap as the text read.
