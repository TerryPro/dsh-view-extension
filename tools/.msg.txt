dsh-diff-view: three panes, two draggable dividers

Layout per the request: the commit list above the file list on the left, the
comparison on the right, with a divider between the two axes.

- both dividers are role="separator": pointer drag AND arrow keys (16px / 4% a
  step), with a floor and a ceiling on each
- geometry lives in custom properties on the container, so a drag writes ONE
  variable per pointermove and renders nothing until release, when the choice is
  persisted (dsh-diff-view.leftWidth / .leftSplit)
- the vertical share is stored as a percentage so a window resize cannot break the
  layout; the width is stored in pixels
- real bug this found: the first version added a pixel delta to a percentage, so
  the history/files divider jumped to nonsense values. The gesture is now pixels
  throughout and converts once, on commit.

The harness learned two things it was silently lying about: it never invoked refs
(callback OR object), and its host elements had no style object or box. Every
behaviour reading a ref — the editor's textarea registry, this view's divider
geometry — was therefore untested and only appeared to work because each caller
had a fallback.

290 client checks, 170 host checks.
