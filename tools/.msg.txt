dsh-diff-view: richer commit rows, and an order toggle

A commit row now carries what one `git log` can honestly give (no process per row):
the subject, the short id, the author (address on hover), the relative time
(absolute on hover), the branch/tag decorations from %D, a merge marker from the
parent count, and the change size from --numstat as "N files +x -y" with a `bin`
mark for binaries. --numstat rather than --shortstat because the latter's text is
LOCALIZED: parsing "3 files changed" would tie the UI to one language.

The order toggle flips the loaded page between newest-first and oldest-first and
remembers the choice. The page itself is always READ newest-first, so the label
says "within the loaded page" rather than pretending the history was re-read.

Also: the client now normalizes commit entries, because the browser and host
halves reload independently -- a row must not crash on a Host that still answers
the older shape (no refs/parents/counts). Two tests cover that skew. And the
"not a repository" notice no longer tells the reader to switch to a scope that no
longer exists.

176 host checks, 302 client checks.
